# StudentKit Pro+

A free, public toolkit for college students: about 40 tools for PDFs, documents, practical/lab files, studying, images, code and text. Files are processed in the browser and never uploaded.

Highlights: a searchable home with pinned/recent tools and a ⌘K command palette, a consistent tool workspace, a Stamp Studio to design editable seals and place them on PDFs/images, a watermark remover for your own documents, and a "My Semester" dashboard (attendance, CGPA, deadlines, timetable, focus streak).

No account is needed. Students can optionally sign in with an emailed code to sync their saved data (stamps, signatures, study data) across devices.
