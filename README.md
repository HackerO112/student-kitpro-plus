## 🚀 What is it?

**StudentKit Pro+** is a complete, free, public toolkit built for college students. It bundles about **40 small tools** that cover everything a student touches day to day — **PDFs, documents, practical/lab files, studying, images, code, and plain text** — all inside a single app.

### The core idea
You're a student. You have lab reports to format, PDFs to merge, watermarks to strip, CGPA to track, deadlines to meet, and code to tidy. Instead of opening ten different websites, StudentKit Pro+ puts all of it in one place, works offline-first, and keeps your files private.

### Privacy by design
- ✅ **Files are processed entirely in your browser** — nothing is uploaded to a server.
- ✅ **No account required** to use any tool.
- ✅ Optional sign-in (emailed code) only to **sync** your stamps, signatures, and study data across devices.

## 🏗️ Tech stack

- **React 18** + **TypeScript** — UI and type safety
- **Vite** — fast dev server and production build
- **Tailwind CSS** + **Radix UI** + **Framer Motion** — styling, accessible components, animations
- **Lucide React**, **Sonner**, **React Hook Form**, **Zod**, **TanStack Query**, **Recharts**, **Tiptap**
- **pdf-lib**, **pdf.js-dist**, **docx**, **mammoth**, **jszip** — document handling in the browser
- **ZiteJS** — app runtime, backend, auth, and sync
- **YouTube API** — video/learning integrations
- **Gemini API** (@google/generative-ai) — AI features

## 🤖 How it was built

This project was **completely created with the help of Zite AI (vibe coding)** — from scaffold to running app — and integrates the **YouTube API** and **Gemini API**. It was built by describing what the student toolkit should do and letting Zite AI generate the structure, components, and tool logic, then refining it into the live app at https://student-kit-proplus.zite.so/.

## 🛠️ Run it locally

```bash
# install dependencies
yarn install

# start the dev server
yarn dev

# build for production
yarn build

# preview the production build
yarn preview
```

Requires **Node.js** and **Yarn**.
