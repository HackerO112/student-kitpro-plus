# Security Policy

## Reporting a vulnerability

Please do not publish exploitable details, personal data, credentials, or tokens in public issues. Use GitHub's private vulnerability reporting / Security Advisories for this repository when available. If private reporting is unavailable, contact the repository owner privately through GitHub.

Include the affected commit or release, environment, impact, and minimal reproduction steps. Redact API keys, passwords, cookies, access tokens, user records, and private URLs.

## Scope and response

This is a best-effort maintainer contact policy, not a guaranteed response-time or bug-bounty commitment. Do not test against systems or data you do not own or have permission to assess.
